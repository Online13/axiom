# Empty

## Covered by `empty.test.tsx`

- `Empty.Header` is one accessible element, read as title then description.
- `Empty.Title` is a header.
- Actions in `Empty.Content` stay outside the header and are reachable on their own.
- Children of `Empty.Media` replace the icon tile.
- The `sm` size renders the same structure.

## Checked on a device

- Centered in the remaining height with `fill`, in a screen and in a sheet.
