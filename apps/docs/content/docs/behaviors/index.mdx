Axiom doesn't stop at components. Over time, it covers the behaviors every mobile app needs. Some already exist as components or hooks; the rest are planned.

Each card links to the behavior's page and shows its status:

- **Available**: a component or hook you can install today.
- **Spec**: the pattern is described, but not implemented yet.
- **Planned**: on the list, not described yet.
