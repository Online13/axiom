Axiom doesn't stop at components. Over time, it covers the behaviors every mobile app needs. Some already exist as components or hooks; the rest are planned.

Each card shows its status:

- **Available**: a component or hook you can install today. The card links to it.
- **Spec**: the pattern has a page describing it, but no implementation yet.
- **Planned**: on the list, with no page yet.
