<Callout title="Draft">The values shown here are conceptual and may change.</Callout>

The palette holds every raw color. Each hue has eleven steps, from light (`50`) to dark (`950`). Step `500` is the iOS system color.

<PaletteGrid />

## Shape

```ts title="Conceptual"
export const palette = {
  gray: {
    50: '#F4F4F4',
    100: '#E7E7E8',
    200: '#D1D1D3',
    300: '#B8B8BC',
    400: '#A3A3A7',
    500: '#8E8E93',
    600: '#78787D',
    700: '#616165',
    800: '#4A4A4D',
    900: '#323235',
    950: '#222225',
  },
  red: { /* … */ },
  // orange, yellow, green, mint, teal, cyan, blue, indigo, purple, pink, brown
} satisfies Palette;
```

## Usage

Components never read the palette. [Colors](/foundations/colors) pick steps from it and give them a role:

```ts title="Conceptual"
export const lightColors = {
  border: { default: palette.gray[200] },
  feedback: { error: palette.red[500] },
} satisfies ThemeColors;
```

To change the brand color, point the semantic colors to another hue, or edit the hue itself.
