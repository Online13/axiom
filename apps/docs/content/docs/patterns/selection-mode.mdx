title: Contextual selection mode
description: "Select items and act on them through a contextual toolbar."
---

<Callout title="Planned">This pattern isn't available yet.</Callout>

When the user starts selecting items (for example with a long press), the screen switches to a selection mode:

- normal navigation can hide;
- a contextual [ToolBar](/templates/tool-bar) appears;
- the available actions change depending on what is selected.
