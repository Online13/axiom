## Swipe actions

Actions available by swiping a row, such as archive, pin or mark as read. Rows are typically built with [Item](/atoms/item).

## Swipe to delete

A specific case of swipe actions, with:

- a threshold past which the swipe triggers deletion;
- an optional confirmation;
- animation;
- deletion;
- undo.
