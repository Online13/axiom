---

<Callout title="Planned">This pattern isn't available yet.</Callout>

Almost every screen that loads data goes through the same states. This abstraction standardizes them so each screen doesn't reinvent the switch.

```text
loading → content
        → empty
        → error → retry → loading
```

## States

- loading;
- content;
- empty;
- error;
- retry.
