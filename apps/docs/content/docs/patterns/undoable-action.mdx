---
title: Undoable action
description: "An action that can be cancelled for a few seconds."
---

<Callout title="Planned">This pattern isn't available yet.</Callout>

Instead of asking for confirmation up front, the action happens right away and the user gets a few seconds to undo it. This keeps common actions fast while still protecting against mistakes.

A [Snackbar](/atoms/snackbar) with an "Undo" action is the usual way to offer it.
