Axiom is a set of files copied into your project, so a coding agent works on your code, not on a package it can only read from the outside. What it misses is the context around those files: which component belongs to which level, which tokens exist, what the CLI copies, how a pattern is meant to be assembled.

This section is about handing over that context.
