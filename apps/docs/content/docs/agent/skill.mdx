A skill is a set of instructions an agent loads when it recognizes the task at hand. Where [MCP](/agent/mcp) gives an agent the facts, a skill gives it the habits: reach for an existing atom before writing one, style through tokens rather than raw values, keep behavior in core primitives.

## What it would cover

- Picking the right level: atom, molecule, organism, template.
- Styling through theme tokens, never hardcoded colors or spacing.
- Composing patterns from the documented behaviors instead of reinventing them.
