## Installation

```npm
npx axiom add text-area
```

Also copies [`input`](/docs/components/input): TextArea uses its tokens, its `Field` parts and `use-input.ts`.

## Usage

```tsx
import { Field } from "@/components/ui/input";
import { TextArea } from "@/components/ui/text-area";

<Field>
	<Field.Label>Message</Field.Label>
	<TextArea autoGrow value={message} onChangeText={setMessage} />
</Field>;
```

Like [Input](/docs/components/input), `TextArea` is the control alone. The label, description, error and a character count are things you write around it, in a [`Field`](/docs/components/input#field).

## Props

`TextArea` accepts the same props as [Input](/docs/components/input) (`invalid`, `disabled`, `containerStyle`, `ref`, and every `TextInput` prop) except `prefix`, `suffix` and `size`, plus:

| Prop        | Type                               | Default     | Description                                                                                           |
| ----------- | ---------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------- |
| `autoGrow`  | `boolean`                          | `false`     | The field gets taller as lines are added, between `minRows` and `maxRows`. Past `maxRows` it scrolls. |
| `minRows`   | `number`                           | `3`         | Height when empty, in lines of body text. Lines get taller with larger system text, up to 1.5×.       |
| `maxRows`   | `number`                           | `8`         | Height limit with `autoGrow`. Keeps the field from pushing the rest of the screen off.                |
| `maxLength` | `number`                           | —           | Hard character limit, from `TextInput`.                                                               |
| `variant`   | `'outline' \| 'filled' \| 'plain'` | `'outline'` | `plain` has no border or padding, for full-screen editors. It grows to fill its container.            |

### Feedback with a character limit

A count next to the description tells the user how much room is left. It's a `Text` you write, so its place and its wording are yours.

<PhonePreview size="sm">

		</span>
		<span class="ax-appbar-title">Report a problem</span>
		<span class="ax-icon-btn" />
	</div>
	<div class="ax-body" style={{ gap: "14px" }}>
		<div class="ax-segmented">
			<span data-active>Bug</span>
			<span>Idea</span>
			<span>Other</span>
		</div>
		<div class="ax-field" data-state="invalid">
			<span class="ax-label">What happened?</span>
			<div
				class="ax-textarea"
				style={{ boxShadow: "inset 0 0 0 1.5px var(--ax-feedback-error)" }}
			>
				The export button does nothing on the Q3 report when I'm offline,
				and then it crashes after reconnecting. Steps: open the report, turn
				on airplane…
			</div>
			<div class="ax-row" data-justify="between">
				<span class="ax-helper">Keep it under 200 characters.</span>
				<span class="ax-counter ax-danger">200 / 200</span>
			</div>
		</div>
	</div>
</PhonePreview>

```tsx
<Field>
	<Field.Label>What happened?</Field.Label>
	<TextArea maxLength={200} value={text} onChangeText={setText} />
	<View style={{ flexDirection: "row", gap: 12 }}>
		<Field.Description style={{ flex: 1 }}>
			Steps help us reproduce it.
		</Field.Description>
		<Text variant="footnote" color={text.length >= 200 ? "error" : "muted"}>
			{text.length} / 200
		</Text>
	</View>
</Field>
```

```tsx

	onChangeText={setBody}
	accessibilityLabel="Note"
```
