Each style sets a font size, a line height, a weight and a font family together. The names and sizes follow the iOS text styles. Display styles carry negative `letterSpacing`, so headings stay tight at large sizes; body styles leave it at zero.

<TypeScale />

Two fonts cover the whole scale: `heading` for titles, `body` for everything else. `undefined` keeps the system font.

```ts title="Conceptual"
export const fonts: Fonts = {
	heading: undefined,
	body: undefined,
};

export const typography = {
	largeTitle: {
		fontSize: 34,
		lineHeight: 40,
		fontWeight: "800",
		letterSpacing: -0.8,
		fontFamily: fonts.heading,
	},
	title1: { /* … */ fontFamily: fonts.heading },
	title2: { /* … */ fontFamily: fonts.heading },
	title3: { /* … */ fontFamily: fonts.heading },
	headline: { /* … */ fontFamily: fonts.heading },
	body: { fontSize: 17, lineHeight: 23, fontWeight: "400", fontFamily: fonts.body },
	callout: { fontSize: 16, lineHeight: 21, fontWeight: "400" },
	subheadline: { fontSize: 15, lineHeight: 20, fontWeight: "400" },
	footnote: { fontSize: 13, lineHeight: 18, fontWeight: "500" },
	caption: { fontSize: 12, lineHeight: 16, fontWeight: "500" },
} satisfies Typography;
```

## Usage

[Title](/docs/atoms/title) and [Text](/docs/atoms/text) map their props onto these styles, so you rarely read them directly:

```tsx title="Conceptual"
<Title level={1}>Settings</Title> // largeTitle
<Text>Saved automatically.</Text> // body
```

## Custom fonts

Load the fonts with [expo-font](https://docs.expo.dev/versions/latest/sdk/font/), then set their names in `fonts`:

```ts title="theme/tokens.ts"
export const fonts: Fonts = {
	heading: "Fraunces_600SemiBold",
	body: "Inter_400Regular",
};
```

`largeTitle` to `headline` use `heading`; `body` to `caption` use `body`. Every component reads the typography styles, so the change reaches them all.

A font file holds a single weight on Android. When a family has one file per weight, the `fontWeight` of a style does not switch files: pick the file that matches the weight you want most, or give a style its own `fontFamily`.
