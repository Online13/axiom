</Callout>

Metrics are layout constants that apply across the whole app rather than to one element.

<MetricsPreview />

```ts title="Conceptual"
export const metrics = {
	touchTarget: 44,
	pressScale: 0.97,
	screenMargin: 16,
	hairline: StyleSheet.hairlineWidth,
} satisfies Metrics;
```

| Key            | Default          | Use                                                     |
| -------------- | ---------------- | ------------------------------------------------------- |
| `touchTarget`  | 44pt             | Minimum touch area of anything pressable                |
| `pressScale`   | 0.97             | Scale a button-like element takes while it is held      |
| `screenMargin` | 16pt             | Horizontal padding between content and the screen edges |
| `hairline`     | 1 physical pixel | Separators and thin borders                             |

## Usage

[Tappable](/docs/core/tappable) reads `touchTarget` and adds `hitSlop` when an element is smaller, so a 24pt icon button still gets a 44pt touch area.

`pressScale` is the value [Button](/docs/atoms/button), [IconButton](/docs/atoms/icon-button) and [FloatingButton](/docs/atoms/floating-button) hand to `Tappable`'s `pressScale` prop. Lower it for a firmer press, or set it to `1` to keep the fill change as the only feedback.

```tsx title="Conceptual"
<ScrollView
	contentContainerStyle={{ paddingHorizontal: tokens.metrics.screenMargin }}
/>
```
