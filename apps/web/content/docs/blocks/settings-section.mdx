## Installation

```npm
npx axiom add settings-section
```

Also copies: the [`settings-item`](/docs/compositions/settings-item) composition, [`separator`](/docs/atoms/separator), [`text`](/docs/atoms/text) and their dependencies. The file lands in `components/blocks/settings-section.tsx`.

## Usage

```tsx
import { SettingsSection } from "@/components/blocks/settings-section";
import { SettingsItem } from "@/components/compositions/settings-item";

<SettingsSection title="Notifications" footer="Quiet hours mute every alert.">
	<SettingsItem
		icon="bell"
		title="Push notifications"
		trailing="switch"
		checked={push}
		onCheckedChange={setPush}
	/>
	<SettingsItem
		icon="calendar"
		title="Quiet hours"
		value="22:00 – 07:00"
		onPress={() => router.push("/settings/quiet-hours")}
	/>
</SettingsSection>;
```

A settings screen is a [Scaffold](/docs/templates/scaffold) with a scroll view and one Settings Section per group.

## Structure

```text
SettingsSection
├── title        Text, footnote, muted, semibold (a header for screen readers)
├── rows         your SettingsItem children
│   └── between each pair: Separator, subtle, inset to the rows' margin
└── footer       Text, footnote, muted
```

The title and footer are aligned to the screen margin (`metrics.screenMargin`). The rows sit on the screen background, without a card around them.

## Props

| Prop       | Type        | Default | Description                                                                                  |
| ---------- | ----------- | ------- | -------------------------------------------------------------------------------------------- |
| `title`    | `string`    | —       | Header above the rows, announced as a header.                                                |
| `footer`   | `string`    | —       | Note under the rows, to explain a setting.                                                   |
| `children` | `ReactNode` | —       | `SettingsItem` rows. A hairline separates them; other elements are separated the same way.   |

## Built with

- [Settings Item](/docs/compositions/settings-item): the rows. A composition built on [Item](/docs/atoms/item).
- [Separator](/docs/atoms/separator): the inset hairlines between rows.
- [Text](/docs/atoms/text): the title and the footer.

```text
Item + Icon + Switch + Text  →  Settings Item  →  Settings Section
         primitives              composition         block
```
