## Installation

```npm
npx axiom add app-bar
```

Also copies: [`text`](/docs/components/text), [`title`](/docs/components/title) and their dependencies. Installs `react-native-safe-area-context`.

Colors come from `appBar.default` in the [component tokens](/docs/foundations/component-tokens). The controls are yours: [IconButton](/docs/components/icon-button), [Avatar](/docs/components/avatar), [SearchBar](/docs/components/search-bar) or anything else.

## Usage

```tsx
import { AppBar } from "@/components/ui/app-bar";

<AppBar>
	<AppBar.Row>
		<IconButton
			icon="arrow-left"
			accessibilityLabel="Back"
			onPress={goBack}
		/>
		<AppBar.Center>
			<AppBar.Title>Inbox</AppBar.Title>
			<AppBar.Subtitle>3 unread</AppBar.Subtitle>
		</AppBar.Center>
		<IconButton
			icon="search"
			accessibilityLabel="Search"
			onPress={openSearch}
		/>
	</AppBar.Row>
</AppBar>;
```

Every part is a plain `View` or text that renders its children where you write them. The bar doesn't look for a title or sort its children: the row shows what you put in it, in that order. To change the structure, change what you write, not the bar.

| Part                              | What it is                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------------- |
| `AppBar`                          | The surface: background, top safe-area inset and an optional hairline.                 |
| `AppBar.Row`                      | The 64pt row of controls.                                                              |
| `AppBar.Center`                   | Fills the row between the controls. Empty, it pushes the controls after it to the end. |
| `AppBar.Expanded`                 | The block under the row, for a medium or large title.                                  |
| `AppBar.Title`, `AppBar.Subtitle` | Text in the bar colors, at the `small`, `medium` or `large` size.                      |

## Props

### AppBar

Takes every `View` prop.

| Prop       | Type                   | Default | Description                                                                              |
| ---------- | ---------------------- | ------- | ---------------------------------------------------------------------------------------- |
| `bordered` | `boolean`              | `false` | Draws a hairline under the bar. Useful when content can scroll behind it.                |
| `safeArea` | `boolean`              | `true`  | Adds the top safe-area inset. Set it to `false` when `Scaffold` already owns that inset. |
| `style`    | `StyleProp<ViewStyle>` | —       | Overrides the surface, for example `backgroundColor` to match the screen.                |

### AppBar.Row, AppBar.Expanded

Take every `View` prop. The row is `APP_BAR_HEIGHT` (64pt) tall, with a small gap between its children. `APP_BAR_HEIGHT` is exported next to the bar.

### AppBar.Center

Takes every `View` prop.

| Prop    | Type      | Default | Description                                                                     |
| ------- | --------- | ------- | ------------------------------------------------------------------------------- |
| `inset` | `boolean` | `false` | Lines the start up with the screen margin, for a row without a leading control. |

### AppBar.Title, AppBar.Subtitle

Take every [Title](/docs/components/title) and [Text](/docs/components/text) prop, except `variant`.

| Prop            | Type                             | Default                                               | Description                                       |
| --------------- | -------------------------------- | ----------------------------------------------------- | ------------------------------------------------- |
| `size`          | `'small' \| 'medium' \| 'large'` | `'small'`                                             | `small` in the row, `medium` or `large` under it. |
| `numberOfLines` | `number`                         | Title: `1` when `small`, `2` otherwise. Subtitle: `1` | Maximum lines before truncation.                  |

The title is announced as a heading.

## Scroll behavior

The bar has no animation of its own. A screen that animates it wraps the parts in `Animated.View` and drives them from its scroll handler, so a static bar costs nothing and the animation stays readable in the screen that owns it:

- [Collapsible header](/docs/behaviors/collapsible-header) folds `AppBar.Expanded` into the row.
- [Scroll-aware AppBar](/docs/behaviors/scroll-aware-app-bar) fades in a surface layer and the row title.
- [Hide-on-scroll](/docs/behaviors/hide-on-scroll) moves the whole bar.
