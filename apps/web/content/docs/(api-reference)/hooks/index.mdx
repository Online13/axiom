---

Hooks hold behavior without any UI. Each one is usable on its own, without adopting the rest of the system.

<Cards>
	<Card title="useControllableState" href="/docs/hooks/use-controllable-state">
		Controlled or uncontrolled state, used by every Axiom input.
	</Card>
	<Card title="useOverlayBackHandler" href="/docs/hooks/use-overlay-back-handler">
		Close a sheet, dialog or menu on a back action instead of leaving the
		screen.
	</Card>
	<Card title="useRefreshControl" href="/docs/hooks/use-refresh-control">
		Pull-to-refresh for any list or ScrollView.
	</Card>
	<Card title="useHideOnScroll" href="/docs/hooks/use-hide-on-scroll">
		Bars that slide out on scroll down and come back on scroll up.
	</Card>
	<Card title="useCollapsibleHeader" href="/docs/hooks/use-collapsible-header">
		A large header that shrinks into a compact bar as the list scrolls.
	</Card>
	<Card title="useScrollToTop" href="/docs/hooks/use-scroll-to-top">
		A scroll-to-top button past a threshold, plus tab press and status bar
		tap.
	</Card>
	<Card title="useScrollAwareAppBar" href="/docs/hooks/use-scroll-aware-app-bar">
		An AppBar that gets a background, a hairline and its title as content
		scrolls under it.
	</Card>
	<Card title="useSwipeActions" href="/docs/hooks/use-swipe-actions">
		Actions revealed by swiping a row, with an optional full swipe.
	</Card>
	<Card title="useDragToReorder" href="/docs/hooks/use-drag-to-reorder">
		Lift a row and drag it to a new position in a list.
	</Card>
</Cards>
