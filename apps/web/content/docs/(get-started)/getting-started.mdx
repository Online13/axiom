All you need is an Expo or React Native app. Run these at its root.

## 1. Initialize

```npm
npx axiom init
```

Pick the styling tool you already use:

```txt title="Terminal" noCopy
◆  Which styling tool does your project use?
│  ● stylesheet
│  ○ unistyles
│  ○ nativewind
│  ○ uniwind
└
```

That's the only question. `init` copies the theme and the headless core, fixes your `tsconfig.json` aliases if needed, and saves your choices in `axiom.json`.

## 2. Add a component

```npm
npx axiom add button
```

The button lands in `components/ui/button.tsx`, in the variant that matches your styling, with anything it depends on.

## 3. Use it

```tsx
import { Button } from "@/components/ui/button";

export function SaveButton() {
	return <Button>Save</Button>;
}
```

Run your app. The button is there, and the file is yours: open it and change whatever you want.

## Keep going

Add the next piece your screen needs. Whatever it relies on comes with it:

```npm
npx axiom add bottom-sheet
```
