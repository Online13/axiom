## Installation

```npm
npx axiom add settings-item
```

Also copies: [`item`](/docs/atoms/item), [`icon`](/docs/atoms/icon), [`switch`](/docs/atoms/switch), [`text`](/docs/atoms/text), the [`use-controllable-state`](/docs/hooks/use-controllable-state) hook and their dependencies. The file lands in `components/compositions/settings-item.tsx`.

Requires the `chevron-right` icon in your [icon registry](/docs/atoms/icon#icons-that-components-need). Settings Item brings no tokens of its own: colors come from [Item](/docs/atoms/item) and [Switch](/docs/atoms/switch).

## Usage

```tsx
import { SettingsItem } from "@/components/compositions/settings-item";

<SettingsItem
	icon="bell"
	title="Notifications"
	trailing="switch"
	checked={notifications}
	onCheckedChange={setNotifications}
/>

<SettingsItem
	icon="globe"
	title="Language"
	value="English"
	onPress={() => router.push("/settings/language")}
/>
```

Group rows with the [Settings Section](/docs/blocks/settings-section) block, which adds a title, a footer and the separators between rows.

## Props

| Prop              | Type                      | Default     | Description                                                                                                                        |
| ----------------- | ------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `title`           | `string`                  | —           | Label of the setting.                                                                                                              |
| `description`     | `string`                  | —           | Second line under the title, up to two lines. Read with the title by screen readers.                                               |
| `icon`            | `IconName`                | —           | Leading [Icon](/docs/atoms/icon), in the muted color.                                                                              |
| `value`           | `string`                  | —           | Current value in muted text, before the chevron or the switch: `"English"`, `"On"`.                                                |
| `trailing`        | `'chevron' \| 'switch'`   | `'chevron'` | `chevron` for a row that opens a screen. `switch` for a setting toggled in place.                                                  |
| `checked`         | `boolean`                 | —           | State of the switch. Without it, the switch manages its own state.                                                                 |
| `onCheckedChange` | `(checked: boolean) => void` | —        | Called when the switch changes.                                                                                                    |
| `onPress`         | `() => void`              | —           | Called when the row is pressed. With `trailing="switch"` and no `onPress`, pressing anywhere on the row toggles the switch, with a light haptic. |
| `disabled`        | `boolean`                 | `false`     | Blocks presses and uses the disabled color for the icon, the value and the switch.                                                 |

## Accessibility

A switch row is announced as a switch with its checked state: the row carries the role, and the switch inside is hidden from screen readers so it isn't read twice. A chevron row is a regular pressable row.

## Built with

- [Item](/docs/atoms/item): the pressable row, its leading, content and trailing slots.
- [Icon](/docs/atoms/icon): the leading icon and the chevron.
- [Switch](/docs/atoms/switch): the trailing toggle.
- [Text](/docs/atoms/text): the value.
