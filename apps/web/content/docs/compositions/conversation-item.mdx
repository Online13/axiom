Unread conversations have a bold name, a time in the link color and a counter. A muted one keeps its counter gray. Without a photo, the avatar shows the initials on a hue taken from the name.

## Installation

```npm
npx axiom add conversation-item
```

Also copies: [`item`](/docs/atoms/item), [`avatar`](/docs/atoms/avatar), [`badge`](/docs/atoms/badge), [`text`](/docs/atoms/text) and their dependencies. The file lands in `components/compositions/conversation-item.tsx`. It brings no tokens of its own.

## Usage

```tsx
import { ConversationItem } from "@/components/compositions/conversation-item";

<ConversationItem
	name={chat.title}
	avatar={chat.avatarUrl ? { uri: chat.avatarUrl } : undefined}
	status={chat.online ? "online" : undefined}
	preview={chat.lastMessage.text}
	time={formatRelative(chat.lastMessage.sentAt)}
	unreadCount={chat.unreadCount}
	muted={chat.muted}
	onPress={() => router.push(`/chats/${chat.id}`)}
	onLongPress={() => openChatMenu(chat)}
/>;
```

The row doesn't format the time: pass `"9:41"` for today, `"Yesterday"`, then a weekday or a date, like Messages.

## Props

| Prop          | Type                  | Default | Description                                                                                   |
| ------------- | --------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `name`        | `string`              | —       | A person or a group. Gives the avatar its initials and hue when there is no photo.            |
| `avatar`      | `ImageSourcePropType` | —       | The photo, in an `lg` [Avatar](/docs/atoms/avatar).                                           |
| `status`      | `AvatarStatus`        | —       | Presence dot on the avatar: `online`, `away`, `busy`, `offline`.                               |
| `preview`     | `string`              | —       | The last message, up to two lines.                                                            |
| `time`        | `string`              | —       | Already formatted, at the end of the first line.                                              |
| `unreadCount` | `number`              | `0`     | Above 0: bold name, time in the link color and a counter, capped at `99+`.                    |
| `muted`       | `boolean`             | `false` | The counter turns to a neutral badge and the time stays muted.                                |
| `onPress`     | `() => void`          | —       | Opens the conversation.                                                                       |
| `onLongPress` | `() => void`          | —       | Usually opens a menu: pin, mute, delete.                                                      |

## Accessibility

The row reads as one element: "Lena Moreau, 2 unread messages, See you at 8, 9:41". The counter and the presence dot are not read on their own.
