The home of an app: who's signed in on the left, notifications and menu on the right. The notifications button carries a counter.

## Installation

```npm
npx axiom add profile-app-bar
```

Also copies: [`app-bar`](/docs/templates/app-bar), [`avatar`](/docs/atoms/avatar), [`icon-button`](/docs/atoms/icon-button), [`badge`](/docs/atoms/badge), [`tappable`](/docs/core/tappable), [`title`](/docs/atoms/title), [`text`](/docs/atoms/text) and their dependencies. The file lands in `components/compositions/profile-app-bar.tsx`. It brings no tokens of its own.

## Usage

```tsx
import { ProfileAppBar } from "@/components/compositions/profile-app-bar";

<ProfileAppBar
	name={user.firstName}
	avatar={{ uri: user.avatarUrl }}
	greeting={greetingFor(new Date())}
	onProfilePress={() => router.push("/account")}
	actions={[
		{ icon: "notification", label: "Notifications", badge: unreadCount, onPress: () => router.push("/notifications") },
		{ icon: "menu", label: "Menu", onPress: openMenu },
	]}
/>;
```

`icon` takes a name from your [icon registry](/docs/atoms/icon): add `notification` and `menu` to `icons.tsx` first. The greeting is yours to compute, in the user's language: the bar only shows it.

## Props

| Prop             | Type                   | Default     | Description                                                                              |
| ---------------- | ---------------------- | ----------- | ---------------------------------------------------------------------------------------- |
| `name`           | `string`               | —           | The signed-in user. Gives the avatar its initials when there is no photo.                |
| `avatar`         | `ImageSourcePropType`  | —           | The photo, in an `sm` [Avatar](/docs/atoms/avatar).                                      |
| `greeting`       | `string`               | —           | Small line above the name: `"Good morning"`.                                             |
| `onProfilePress` | `() => void`           | —           | Makes the avatar and the name one pressable, to open the profile or an account switcher. |
| `profileLabel`   | `string`               | `"Profile"` | Read before the name when pressable: "Profile, Lena Moreau".                             |
| `actions`        | `AppBarAction[]`       | —           | Up to two buttons at the end: `{ icon, label, onPress, badge? }`.                        |
| `bordered`       | `boolean`              | `false`     | Hairline under the bar.                                                                  |
| `safeArea`       | `boolean`              | `true`      | Adds the top safe-area inset. `false` inside [Scaffold](/docs/templates/scaffold).       |
| `style`          | `StyleProp<ViewStyle>` | —           | Styles for the bar.                                                                      |

An action's `badge` is a number for a counter, or `true` for a dot.

## Accessibility

The avatar, the greeting and the name are one element. Pressable, it's a button: "Profile, Lena Moreau". Otherwise it reads "Good morning, Lena Moreau". An action with a counter reads it after its label: "Notifications, 3".
