Article Card is designed for a vertical feed: each card takes the full width of the list, one article per row. There is no width to set.

## Installation

```npm
npx axiom add article-card
```

Also copies: [`card`](/docs/atoms/card), [`avatar`](/docs/atoms/avatar), [`title`](/docs/atoms/title), [`text`](/docs/atoms/text) and their dependencies. The file lands in `components/compositions/article-card.tsx`. It brings no tokens of its own.

## Usage

```tsx
import { ArticleCard } from "@/components/compositions/article-card";

<ArticleCard
	title={article.title}
	image={{ uri: article.cover }}
	category="Cities"
	excerpt={article.summary}
	author={{ name: article.author.name, avatar: { uri: article.author.photo } }}
	meta={`${formatDate(article.publishedAt)} · ${article.readingTime} min read`}
	onPress={() => router.push(`/articles/${article.slug}`)}
/>;
```

`meta` is one line of text: the card doesn't format dates or reading times, so it follows your app's locale.

## Props

| Prop       | Type                   | Default | Description                                                                                     |
| ---------- | ---------------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `title`    | `string`               | —       | The headline, up to three lines.                                                                |
| `image`    | `ImageSourcePropType`  | —       | The cover, in 16:9 at the top of the card.                                                      |
| `category` | `string`               | —       | Above the headline, in capitals and in the `link` color: `"Design"`, `"World"`.                 |
| `excerpt`  | `string`               | —       | Up to two lines under the headline.                                                             |
| `author`   | `ArticleAuthor`        | —       | `{ name, avatar? }`. A small [Avatar](/docs/atoms/avatar) and the name, in the byline.           |
| `meta`     | `string`               | —       | Already formatted, under the author: `"Sep 24 · 6 min read"`.                                   |
| `onPress`  | `() => void`           | —       | Makes the whole card pressable, to open the article. Its label reads the category, headline and author. |
| `style`    | `StyleProp<ViewStyle>` | —       | Extra styles for the card container, for example a margin.                                      |

## Built with
