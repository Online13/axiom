The two variants are separate components with their own code: install the one you need. **Default** is an outlined card with the image edge to edge and the price under the name. **Spotlight** is a filled card where a cut-out product floats on the card's background, price first.

## Installation

<VariantPanel group="product-card" value="default" active>

```npm
npx axiom add product-card
```

Also copies: [`card`](/docs/atoms/card), [`text`](/docs/atoms/text), [`badge`](/docs/atoms/badge), [`button`](/docs/atoms/button) and their dependencies. The file lands in `components/compositions/product-card.tsx`.

Product Card brings no tokens of its own: it uses the `outlined` variant of [Card](/docs/atoms/card), the `highlight` variant of [Badge](/docs/atoms/badge) and the default [Button](/docs/atoms/button).

</VariantPanel>

<VariantPanel group="product-card" value="spotlight">

```npm
npx axiom add product-card-spotlight
```

Also copies: [`card`](/docs/atoms/card), [`text`](/docs/atoms/text), [`title`](/docs/atoms/title), [`badge`](/docs/atoms/badge), [`button`](/docs/atoms/button) and their dependencies. The file lands in `components/compositions/product-card-spotlight.tsx`.

It brings no tokens of its own: it uses the `filled` variant of [Card](/docs/atoms/card), the `headingSm` variant of [Title](/docs/atoms/title) for the price, the `highlight` variant of [Badge](/docs/atoms/badge) and the default [Button](/docs/atoms/button).

</VariantPanel>

## Usage

<VariantPanel group="product-card" value="default" active>

```tsx
import { Image } from "react-native";
import { ProductCard } from "@/components/compositions/product-card";

<ProductCard
	title="Chambray shirt"
	subtitle="Indigo, 3 colors"
	price="$48.00"
	badge="New"
	media={<Image source={{ uri: product.image }} style={{ aspectRatio: 1 }} />}
	onPress={() => router.push(`/products/${product.id}`)}
	onAction={() => cart.add(product.id)}
/>;
```

</VariantPanel>

<VariantPanel group="product-card" value="spotlight">

```tsx
import { Image } from "react-native";
import { ProductCardSpotlight } from "@/components/compositions/product-card-spotlight";

<ProductCardSpotlight
	title="Steel bottle"
	subtitle="Sage, 500 ml"
	price="$25.60"
	badge="-20%"
	media={
		<Image
			source={{ uri: product.cutout }}
			resizeMode="contain"
			style={{ aspectRatio: 1 }}
		/>
	}
	onPress={() => router.push(`/products/${product.id}`)}
/>;
```

Use cut-out images (transparent background) with `resizeMode="contain"`: a photo with its own background would fill the inset and lose the effect.

</VariantPanel>

`price` is a string: format it yourself, currency included, so the card doesn't decide how your app shows money.

## Props

<VariantPanel group="product-card" value="default" active>

| Prop          | Type                   | Default         | Description                                                                                                          |
| ------------- | ---------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------- |
| `title`       | `string`               | —               | Product name, shown as the card title.                                                                               |
| `price`       | `string`               | —               | Already formatted, currency included: `"$24.00"`. Shown in semibold under the title.                                 |
| `subtitle`    | `string`               | —               | Secondary line under the title: a color, a size, a brand.                                                            |
| `badge`       | `string`               | —               | Short label in a `highlight` [Badge](/docs/atoms/badge): `"New"`, `"-20%"`. Sits on the media, or above the title without media. |
| `media`       | `ReactNode`            | —               | Usually an `Image`. It fills the card's width; give it a size or an `aspectRatio`.                                   |
| `actionLabel` | `string`               | `"Add to cart"` | Label of the action button.                                                                                          |
| `onAction`    | `() => void`           | —               | Shows the full-width action button and handles its press. Without it, there is no button.                            |
| `onPress`     | `() => void`           | —               | Makes the whole card pressable, to open the product. The button keeps its own press. The card is read as "title, price". |
| `style`       | `StyleProp<ViewStyle>` | —               | Extra styles for the card container, for example a width in a grid.                                                  |

</VariantPanel>

<VariantPanel group="product-card" value="spotlight">

| Prop          | Type                   | Default         | Description                                                                                                          |
| ------------- | ---------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------- |
| `title`       | `string`               | —               | Product name, on one line under the price.                                                                           |
| `price`       | `string`               | —               | Already formatted, currency included: `"$24.00"`. Shown first, as a `headingSm` [Title](/docs/atoms/title).          |
| `subtitle`    | `string`               | —               | Secondary line under the name: a color, a size.                                                                      |
| `badge`       | `string`               | —               | Short label in a `highlight` [Badge](/docs/atoms/badge), on the product: `"New"`, `"-20%"`.                          |
| `media`       | `ReactNode`            | —               | Required. A cut-out `Image` with `resizeMode="contain"`, inset from the card's edges. Give it a size or an `aspectRatio`. |
| `actionLabel` | `string`               | `"Add to cart"` | Label of the action button.                                                                                          |
| `onAction`    | `() => void`           | —               | Shows the full-width action button and handles its press. Without it, there is no button.                            |
| `onPress`     | `() => void`           | —               | Makes the whole card pressable, to open the product. The button keeps its own press. The card is read as "title, price". |
| `style`       | `StyleProp<ViewStyle>` | —               | Extra styles for the card container, for example a width in a grid.                                                  |

</VariantPanel>

## Built with

- [Card](/docs/atoms/card): the surface (`outlined`, `filled` for Spotlight), its header, title and description.
- [Badge](/docs/atoms/badge): the `highlight` label.
- [Button](/docs/atoms/button): the full-width action.
- [Text](/docs/atoms/text): the price, and the name in Spotlight.
- [Title](/docs/atoms/title): the price in Spotlight.

## Used in

No block uses Product Card yet. It is meant for the product grids of the planned [Commerce](/docs/blocks/commerce) blocks.
