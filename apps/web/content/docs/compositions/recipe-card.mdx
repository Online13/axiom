Recipe Card is designed for a vertical feed: each card takes the full width of the list, one recipe per row. There is no width to set.

## Installation

```npm
npx axiom add recipe-card
```

Also copies: [`card`](/docs/components/card), [`chip`](/docs/components/chip), [`badge`](/docs/components/badge), [`separator`](/docs/components/separator), [`icon`](/docs/components/icon), [`text`](/docs/components/text), [`button`](/docs/components/button) and their dependencies. The file lands in `components/compositions/recipe-card.tsx`. It brings no tokens of its own.

The stat icons come from your [icon registry](/docs/components/icon). Add the ones you use to `icons.tsx`, for example with `expo-symbols`:

```tsx title="components/ui/icons.tsx"
timer: symbol("clock", "schedule"),
servings: symbol("person.2", "group"),
difficulty: symbol("flame", "local_fire_department"),
```

## Usage

```tsx
import { RecipeCard } from "@/components/compositions/recipe-card";

<RecipeCard
	title="Thai red curry"
	description="A fragrant, spicy curry with coconut milk, lemongrass and fresh Thai basil."
	image={{ uri: recipe.photo }}
	badge="Spicy choice"
	stats={[
		{ icon: "timer", value: "20", label: "mins" },
		{ icon: "servings", value: "4", label: "servings" },
		{ icon: "difficulty", value: "Medium" },
	]}
	ingredients={recipe.ingredients}
	onPress={() => router.push(`/recipes/${recipe.id}`)}
	onAction={() => router.push(`/recipes/${recipe.id}/cook`)}
/>;
```

## Props

| Prop             | Type                   | Default           | Description                                                                                    |
| ---------------- | ---------------------- | ----------------- | ---------------------------------------------------------------------------------------------- |
| `title`          | `string`               | —                 | Name of the recipe, shown as the card title.                                                   |
| `description`    | `string`               | —                 | Up to two lines under the title.                                                               |
| `image`          | `ImageSourcePropType`  | —                 | The dish, in 4:3 at the top of the card.                                                       |
| `badge`          | `string`               | —                 | Short label in a `highlight` [Badge](/docs/components/badge), on the photo: `"Spicy"`, `"Quick"`.   |
| `stats`          | `RecipeStat[]`         | —                 | `{ icon?, value, label? }`: time, servings, difficulty. Shown as "**20** mins", between lines. Three fit. |
| `ingredients`    | `string[]`             | —                 | Shown as filled [Chips](/docs/components/chip). The first `SHOWN_INGREDIENTS` (2, a constant in the file) show; the rest are counted in a "+n" chip, read as "n more ingredients". |
| `actionLabel`    | `string`               | `"Start cooking"` | Label of the action button.                                                                    |
| `onAction`       | `() => void`           | —                 | Shows the full-width button. Without it, there is no button.                                   |
| `onPress`        | `() => void`           | —                 | Makes the whole card pressable, to open the recipe. The button keeps its own press.            |
| `style`          | `StyleProp<ViewStyle>` | —                 | Extra styles for the card container, for example a margin.                                     |
