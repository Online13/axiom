## Usage

<VariantPanel group="pricing-card" value="default" active>

```tsx
import { PricingCard } from "@/components/compositions/pricing-card";

{plans.map((plan) => (
	<PricingCard
		key={plan.id}
		name={plan.name}
		price={formatPrice(plan.price)}
		period={plan.price > 0 ? "/month" : undefined}
		description={plan.tagline}
		features={plan.features}
		badge={plan.id === "pro" ? "Most popular" : undefined}
		featured={plan.id === "pro"}
		current={plan.id === subscription.planId}
		onAction={() => purchase(plan.id)}
	/>
))}
```

Feature one plan at most: the border and the solid button only work as a signal when they're alone.

</VariantPanel>

<VariantPanel group="pricing-card" value="compact">

```tsx
import { PricingCardCompact } from "@/components/compositions/pricing-card-compact";
import { RadioGroup } from "@/components/ui/radio";

<RadioGroup value={plan} onValueChange={setPlan} gap={2} accessibilityLabel="Plan">
	<PricingCardCompact value="yearly" name="Yearly" price="$99" period="/year" description="$8.25 a month" badge="Save 30%" />
	<PricingCardCompact value="monthly" name="Monthly" price="$12" period="/month" description="Cancel anytime" />
</RadioGroup>;
```

Each row is a [Radio](/docs/components/radio): it must sit inside a `RadioGroup`, which holds the selected plan. Put the purchase button under the group.

</VariantPanel>

<VariantPanel group="pricing-card" value="toggle">

```tsx
import { PricingCardToggle, type Billing } from "@/components/compositions/pricing-card-toggle";

const [billing, setBilling] = useState<Billing>("yearly");

<PricingCardToggle
	name="Pro"
	monthlyPrice="$12"
	yearlyPrice="$9.60"
	discount="-20%"
	yearlyCaption="$115 billed yearly"
	features={["Unlimited projects", "Priority support"]}
	featured
	billing={billing}
	onBillingChange={setBilling}
	onAction={(choice) => purchase("pro", choice)}
/>;
```

Both prices are for the same period (`/month`), so the struck price compares like with like. With several cards, pass the same `billing` to all of them: switching one switches the others.

</VariantPanel>

## Accessibility

The price and its period are read together: "$12 /month". Buttons are labelled with the plan: "Start free trial, Pro", or "Current plan, Free" while disabled.

Compact and Tile are radios in a `radiogroup`: each is read as one item with its state, "Yearly, $99 /year, $8.25 a month, Save 30%, selected". On Toggle, the yearly price is read with what it replaces: "$9.60 /month, instead of $12, -20%".
