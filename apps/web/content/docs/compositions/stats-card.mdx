## Usage

<VariantPanel group="stats-card" value="default" active>

```tsx
import { StatsCard } from "@/components/compositions/stats-card";

<View style={{ flexDirection: "row", gap: 12 }}>
	<StatsCard
		label="Revenue"
		value="$12,480"
		icon="wallet"
		change="+12.4%"
		trend="up"
		caption="vs last week"
		style={{ flex: 1 }}
	/>
	<StatsCard
		label="Spending"
		value="$3,210"
		icon="cart"
		change="+8%"
		trend="up"
		positive={false}
		style={{ flex: 1 }}
	/>
</View>;
```

</VariantPanel>

<VariantPanel group="stats-card" value="sparkline">

```tsx
import { StatsCardSparkline } from "@/components/compositions/stats-card-sparkline";

<StatsCardSparkline
	label="Revenue"
	value="$12,480"
	icon="wallet"
	data={last7Days.map((day) => day.revenue)}
	change="+12.4%"
	trend="up"
	caption="Last 7 days"
	style={{ flex: 1 }}
/>;
```

`data` is scaled between its own minimum and maximum: the line shows the shape of the series, not its distance from zero. Two points at least; a dozen reads best at this size.

</VariantPanel>

<VariantPanel group="stats-card" value="progress">

```tsx
<StatsCardProgress

	progress={steps / goal}
	icon="flame"

```

</VariantPanel>

</VariantPanel>

<VariantPanel group="stats-card" value="ring">

```tsx
import { StatsCardRing } from "@/components/compositions/stats-card-ring";

<StatsCardRing
	label="Move"
	value="420 kcal"
	progress={420 / 600}
	caption="of 600 kcal"

```

Pass `ringLabel` to replace the percentage in the ring, with something short: `"3/5"`.

</VariantPanel>

Values come formatted: the card never rounds or localizes a number.

## Props

<VariantPanel group="stats-card" value="default" active>

| Prop       | Type                           | Default           | Description                                                                                    |
| ---------- | ------------------------------ | ----------------- | ---------------------------------------------------------------------------------------------- |
| `label`    | `string`                       | —                 | What is measured, muted, above the value.                                                      |
| `value`    | `string`                       | —                 | Already formatted, in large type. Shrinks to fit one line.                                     |
| `icon`     | `IconName`                     | —                 | Before the label.                                                                              |
| `change`   | `string`                       | —                 | Change against the previous period, in a [Badge](/docs/atoms/badge): `"+12.4%"`.               |
| `trend`    | `'up' \| 'down' \| 'flat'`     | `'flat'`          | Direction of the change. `flat` keeps the badge neutral.                                       |
| `positive` | `boolean`                      | `trend !== 'down'` | Whether the change is good news: green if so, red if not. Pass `false` for spending or latency going up. |
| `caption`  | `string`                       | —                 | After the change: `"vs last week"`.                                                            |
| `variant`  | `'elevated' \| 'outlined' \| 'filled'` | `'filled'` | The [Card](/docs/atoms/card) variant.                                                          |
| `onPress`  | `() => void`                   | —                 | Makes the card pressable, to open the detail.                                                  |
| `style`    | `StyleProp<ViewStyle>`         | —                 | Extra styles, usually `flex: 1` in a row of cards.                                             |

</VariantPanel>

## Accessibility

The card reads as one sentence: "Revenue: $12,480, +12.4%, vs last week". The sparkline is hidden from screen readers: the value and the change already say what it shows.

Progress and Ring are progress bars: they announce their percentage along with the label, "Steps: 8,204, / 10,000, 82%, 1,796 to go".

## Built with

- [Card](/docs/atoms/card): the filled surface.
- [Title](/docs/atoms/title): the value.
- [Badge](/docs/atoms/badge): the change, in success, error or neutral.
- [Icon](/docs/atoms/icon) and [Text](/docs/atoms/text): the label and the caption.
- `react-native-svg`: the line of Sparkline and the arc of Ring.
