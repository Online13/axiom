The field takes the place of the title, between the back button and the actions. The filters button carries a counter of active filters.

## Installation

```npm
npx axiom add search-app-bar
```

Also copies: [`app-bar`](/docs/components/app-bar), [`search-bar`](/docs/components/search-bar), [`icon-button`](/docs/components/icon-button), [`text`](/docs/components/text), [`tappable`](/docs/core/tappable) and their dependencies. Installs `react-native-reanimated`, for the Cancel slide. The file lands in `components/compositions/search-app-bar.tsx`. It brings no tokens of its own: colors come from [AppBar](/docs/components/app-bar) and [SearchBar](/docs/components/search-bar).

Requires the `arrow-left` and `close` icons in your [icon registry](/docs/components/icon#icons-that-components-need).

## Usage

A search screen opened from a search button: the field has the focus as soon as the screen appears.

```tsx
import { SearchAppBar } from "@/components/compositions/search-app-bar";

const [query, setQuery] = useState("");

<SearchAppBar
	value={query}
	onChangeText={setQuery}
	onSubmit={runSearch}
	placeholder="Search products"
	autoFocus
	loading={isFetching}
	onNavigate={router.back}
>
	<IconButton
		icon="filter"
		badge={activeFilters.length}
		accessibilityLabel="Filters"
		onPress={openFilters}
	/>
</SearchAppBar>;
```

Opened as a modal, pass `navigation="close"`. With [Scaffold](/docs/components/scaffold), which already pads the status bar, pass `safeArea={false}`.

The actions are the bar's children: write the buttons you need after the field, as many as fit. Every [SearchBar](/docs/components/search-bar) prop goes through to the field. To lay the field out yourself, put a SearchBar in [`AppBar.Center`](/docs/components/app-bar).

### With Cancel

On iOS, a search that's part of the screen often ends with a Cancel button. Pass `onCancel`: the button slides in while the field is focused, from its measured width so the field shrinks smoothly, and stays still with Reduce Motion. A press blurs the field, then calls `onCancel`, where you clear the query or leave the screen.

```tsx
<SearchAppBar
	value={query}
	onChangeText={setQuery}
	placeholder="Search messages"
	onCancel={() => setQuery("")}
/>
```

## Props

| Prop              | Type                    | Default                  | Description                                                                     |
| ----------------- | ----------------------- | ------------------------ | ------------------------------------------------------------------------------- |
| `navigation`      | `'back' \| 'close'`     | `'back'`                 | An arrow, or a cross for a search opened as a modal.                            |
| `onNavigate`      | `() => void`            | —                        | Shows the navigation button.                                                    |
| `navigationLabel` | `string`                | `"Back"` or `"Close"`    | Label of the navigation button.                                                 |
| `children`        | `ReactNode`             | —                        | Buttons after the field, such as filters or scan. Rendered as written.          |
| `onCancel`        | `() => void`            | —                        | Shows a Cancel button while the field is focused. Called after the field blurs. |
| `cancelLabel`     | `string`                | `"Cancel"`               | Label of the Cancel button.                                                     |
| `bordered`        | `boolean`               | `true`                   | Hairline under the bar.                                                         |
| `safeArea`        | `boolean`               | `true`                   | Adds the top safe-area inset.                                                   |
| `barStyle`        | `StyleProp<ViewStyle>`  | —                        | Styles for the bar.                                                             |
| `variant`         | `'filled' \| 'outline'` | `'filled'`               | Look of the field.                                                              |
| …                 | `SearchBarProps`        | —                        | `value`, `onChangeText`, `onSubmit`, `placeholder`, `loading`, `clearable`, `autoFocus`… |

## Accessibility

The field is a search field with its placeholder as a label, from [SearchBar](/docs/components/search-bar). An action with a counter reads it after its label: "Filters, 2".
