The field takes the place of the title, between the back button and the actions. The filters button carries a counter of active filters.

## Installation

```npm
npx axiom add search-app-bar
```

Also copies: [`app-bar`](/docs/templates/app-bar), [`search-bar`](/docs/molecules/search-bar), [`icon-button`](/docs/atoms/icon-button), [`badge`](/docs/atoms/badge) and their dependencies. The file lands in `components/compositions/search-app-bar.tsx`. It brings no tokens of its own: colors come from [AppBar](/docs/templates/app-bar) and [SearchBar](/docs/molecules/search-bar).

Requires the `arrow-left` and `close` icons in your [icon registry](/docs/atoms/icon#icons-that-components-need).

## Usage

A search screen opened from a search button: the field has the focus as soon as the screen appears.

```tsx
import { SearchAppBar } from "@/components/compositions/search-app-bar";

const [query, setQuery] = useState("");

<SearchAppBar
	value={query}
	onChangeText={setQuery}
	onSubmit={runSearch}
	placeholder="Search products"
	autoFocus
	loading={isFetching}
	onNavigate={router.back}
	actions={[
		{ icon: "filter", label: "Filters", badge: activeFilters.length, onPress: openFilters },
	]}
/>;
```

Opened as a modal, pass `navigation="close"`. With [Scaffold](/docs/templates/scaffold), which already pads the status bar, pass `safeArea={false}`.

Every [SearchBar](/docs/molecules/search-bar) prop goes through to the field, except the cancel button: the navigation button takes its place. Use [AppBar with `AppBar.Search`](/docs/templates/app-bar) instead for a large title with a search field under it.

## Props

| Prop              | Type                    | Default                  | Description                                                                     |
| ----------------- | ----------------------- | ------------------------ | ------------------------------------------------------------------------------- |
| `navigation`      | `'back' \| 'close'`     | `'back'`                 | An arrow, or a cross for a search opened as a modal.                            |
| `onNavigate`      | `() => void`            | —                        | Shows the navigation button.                                                    |
| `navigationLabel` | `string`                | `"Back"` or `"Close"`    | Label of the navigation button.                                                 |
| `actions`         | `AppBarAction[]`        | —                        | Up to two buttons after the field: `{ icon, label, onPress, badge? }`.          |
| `bordered`        | `boolean`               | `true`                   | Hairline under the bar.                                                         |
| `safeArea`        | `boolean`               | `true`                   | Adds the top safe-area inset.                                                   |
| `barStyle`        | `StyleProp<ViewStyle>`  | —                        | Styles for the bar.                                                             |
| `variant`         | `'filled' \| 'outline'` | `'filled'`               | Look of the field.                                                              |
| …                 | `SearchBarProps`        | —                        | `value`, `onChangeText`, `onSubmit`, `placeholder`, `loading`, `clearable`, `autoFocus`… |

An action's `badge` is a number for a counter, or `true` for a dot.

## Accessibility

The field is a search field with its placeholder as a label, from [SearchBar](/docs/molecules/search-bar). An action with a counter reads it after its label: "Filters, 2".
